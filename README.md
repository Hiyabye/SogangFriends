# Sogang Friends Bot

서강대 공지, 벨라르미노 식단, 학사 일정을 Discord에서 확인하는 친구 서버용 봇입니다.

## 무엇을 알려주나요?

- **공지**: 공식 게시판 22곳의 새 글을 기관별 채널로 보냅니다. 제목·게시일·원문 링크를 색상 카드로 보여줍니다.
- **식단**: 아침과 저녁에 오늘·내일 식단을 안내합니다. 읽기 어려운 메뉴는 추측하지 않고 공식 메뉴표 이미지나 원문 링크를 함께 제공합니다.
- **학사 일정**: 검토된 학생 대상 일정과 남은 날짜를 일정 채널에서 보여줍니다.
- **도서관 좌석**: 133 로욜라 인벤툼 II의 알림 대상 96석이 만석에서 잔여 좌석이 있는 상태로 바뀌면 지정 채널에 알립니다. 새 알림을 보낸 뒤 이전 알림은 삭제하며, 멘션은 보내지 않습니다.

공지 AI 요약, 개인별 구독, 대화 자동 응답은 제공하지 않습니다.

## 명령어

| 명령어 | 하는 일 |
|---|---|
| `/meal` | 오늘 하루 식단 보기 |
| `/meal date:2026-10-20` | 지정한 날짜의 식단 보기 |
| `/notices` | 최근 수집된 공지 보기 |
| `/notices source:university` | 특정 게시판 공지 보기 |
| `/schedule` | 오늘부터 30일 범위의 학사 일정 보기 |
| `/setup` | 알림 채널 연결 — 서버 관리 권한 필요 |
| `/status` | 수집·발송 상태 확인 — 관리자에게만 표시 |

`/meal`은 현재 주와 다음 주의 자료를 제공합니다. 해당 날짜에 맞는 자료가 없으면 이전 주 식단을 대신 보여주지 않습니다.

## 공지 채널 연결

현재 서버는 아래 **6개 채널만** 사용합니다. 예전 통합 공지 채널은 제거했습니다.

| 채널 | 포함하는 게시판 | `/setup` 옵션 |
|---|---|---|
| 서강대학교 | 학사·학생 일반·장학·일반·행사특강·Onestop 공지 | `university` |
| 소프트웨어융합대학 | 학사·대학원·대외정보·소식·취업·인턴십 | `computing` |
| SW중심대학사업단 | 공지사항·소식·언론보도 | `swedu` |
| 융합교육원 | 공지사항·센터소식 | `convedu` |
| 빅데이터융복합사업단 | 공지사항·News | `bdata` |
| 공과대학 | 일반공지·채용/홍보·학사공지·연구성과 | `engineering` |

관리자는 Discord에서 채널을 선택해 연결할 수 있습니다.

```text
/setup university:#서강대학교 computing:#소프트웨어융합대학 swedu:#sw중심대학사업단 convedu:#융합교육원 bdata:#빅데이터융복합사업단 engineering:#공과대학
/setup meals:#식단 schedule:#학사일정
/setup library:#도서관좌석
```

바꿀 옵션만 입력하면 나머지 설정은 유지됩니다. 채널을 연결하거나 바꿔도 과거 공지를 다시 보내지 않습니다.

`notices` 옵션은 기관별 채널이 없는 경우에만 사용하는 공통 채널입니다. 현재 서버에서는 설정하지 않습니다. 기관별 채널과 공통 채널이 모두 없으면 그 기관의 자동 알림은 보내지 않습니다.

> 새 게시판의 기존 글은 첫 수집 때 알림 없이 등록합니다. 최근 수집은 게시판별 일부 페이지만 확인하며, 산하 전공 사이트나 학교의 모든 게시판을 포함하지는 않습니다.

## 알림은 언제 오나요?

모든 시간은 **한국 시간(KST)** 기준입니다.

| 내용 | 시간 |
|---|---|
| 새 공지 확인 | 03:10 · 09:10 · 15:10 · 21:10 |
| 아침 식단 보고 | 07:00 — 오늘 아침 + 오늘 저녁 |
| 저녁 식단 보고 | 17:30 — 오늘 저녁 + 내일 아침 |
| 학사 일정 게시물 최초 생성 | 07:30 |
| 인벤툼 II 좌석 확인 | 10:00–21:59, 1분마다 |

식단 자료는 보고 전인 06:40·17:10에 갱신을 시도합니다. 수집 서비스가 지연되면 최신 내용 반영도 늦어질 수 있습니다.

기존 식단·일정 게시물은 15분마다 변경을 확인합니다. 식단은 표시 내용이 바뀌면 새 메시지를 올리고 이전 메시지를 지우며, 일정은 기존 메시지를 편집합니다. 놓친 게시 시각의 메시지를 나중에 몰아서 보내지는 않습니다.

식단 보고에는 컵밥을 제외하며, `/meal`에서는 하루 전체 항목을 볼 수 있습니다. 새 메시지 알림을 받고 싶다면 Discord 채널 알림을 **모든 메시지**로 설정하세요. 봇은 멘션을 보내지 않습니다.

도서관 알림은 매일 첫 확인과 3분 이상 수집이 끊긴 뒤 첫 확인에서는 보내지 않습니다. 잔여 좌석이 있어도 만석→잔여 전환을 관측하지 않으면 알리지 않습니다. 장애인석 1·3·44·85번과 리클라이너석 101·102번은 알림 대상에서 제외합니다. 짧은 빈자리는 놓칠 수 있습니다. 좌석을 예약하거나 도착 시 이용을 보장하지 않습니다.

## 안 보이거나 내용이 이상할 때

- **메시지가 안 와요**: 관리자가 `/status`와 채널 연결을 확인해 주세요. 봇에 채널 보기·메시지 보내기 권한이 필요합니다. 일정 카드에는 링크 임베드, 이미지·파일에는 파일 첨부 권한도 필요합니다.
- **식단에 오타가 있어요**: 이미지 문자 인식 결과라 메뉴명에 오타가 있을 수 있습니다. 날짜에 맞는 원문을 함께 확인해 주세요. 읽지 못한 메뉴는 미확인으로 남깁니다.
- **공지나 일정이 최신이 아니에요**: 공지는 수집 시점의 자료이며, 학사 일정은 사람이 검토해 등록합니다. 중요한 신청·마감은 공식 원문을 확인해 주세요.
- **같은 메시지를 다시 보내도 될까요?**: 발송 결과가 불확실한 경우 중복을 막기 위해 자동 재전송하지 않습니다. 관리자가 실제 채널 기록을 먼저 확인해야 합니다.
